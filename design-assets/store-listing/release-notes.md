# Google Play 发布说明

## English

### Version 1.0.1

Welcome to Nurtlina.

• Quickly log feeding, diaper changes and sleep
• See today’s summary and recent care history
• Get optional, calm feeding reminders
• Keep logging when you are offline
• Review trends, use widgets and export supported records
• Sign in for supported backup and sync features

We also improved stability, accessibility and the night-time experience.

Nurtlina provides tracking and reminders only, not medical advice.
