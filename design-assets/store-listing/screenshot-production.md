# 商店截图制作脚本与演示数据

## 固定演示档案

- 宝宝昵称：`Milo`（所有英语素材统一使用）
- 中文昵称：`小米`（简体中文素材统一使用）
- 不使用姓氏、头像、真实生日、真实邮箱或真实账号。
- 所有时间和记录仅用于演示，不代表喂养建议。

## 建议演示记录

以截图当天 `08:00` 为画面基准，使用下列虚构数据：

| 时间 | 类型 | 内容 |
|---|---|---|
| 00:40 | Feeding | Breast milk, 90 ml |
| 02:10–04:20 | Sleep | 2 h 10 min |
| 04:35 | Diaper | Wet |
| 04:50 | Feeding | Formula, 120 ml |
| 06:15–07:25 | Sleep | 1 h 10 min |
| 07:35 | Diaper | Mixed |

不要把这些数值描述为推荐量、正常范围或健康标准。

## 逐张拍摄脚本

### 01 — Today / Quick Feed

- 浅色模式。
- Today 页面完整加载。
- 显示 Quick Actions 和 Today Summary。
- 不显示广告加载失败、同步错误或权限弹窗。

### 02 — New Feed

- 打开新增喂养面板。
- 选择 Breast milk，数量 90 ml。
- 保证保存按钮和主要字段完整可见。

### 03 — Today Summary

- 显示当天 Feeds、Diapers、Sleep 摘要。
- 数据来自固定演示档案。

### 04 — Reminder

- 显示应用内 Feeding window 或系统通知。
- 通知文字保持平静，不使用危险、逾期或健康警告。
- 截图前清除其他应用通知和真实账号信息。

### 05 — Logs

- 展示喂养、尿布和睡眠混合时间线。
- 确保记录名称完整，不出现调试标记。

### 06 — Insights

- 使用至少 7 天的虚构数据生成趋势。
- 保留“仅反映已记录数据，并非医疗建议”的说明。
- 不添加正常值、目标线或风险评级。

### 07 — Offline

- 关闭网络后成功新建一条记录。
- 仅展示本地保存成功，不声称已经完成云同步。

### 08 — Accessibility / Pro

- 优先展示深色模式和较大字体。
- 如果展示 Pro 权益，必须使用实际已上线能力。
- 不在夜间画面显示广告、评分弹窗或付费墙。

## 验收

- [ ] 竖版输出为 `1080 × 1920 px`。
- [ ] 所有截图来自当前发布候选版本。
- [ ] 状态栏、通知栏和账号区域没有真实个人信息。
- [ ] 字体没有裁切，按钮没有被装饰框遮挡。
- [ ] 各语言界面与标题一致。
- [ ] 画面没有医疗、安全或权威背书暗示。
- [ ] 截图没有展示已移除的奶瓶状态机或奶瓶计时器。
